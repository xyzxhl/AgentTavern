# 青云上文风库

共 36 种文风，按分类整理。勾选预设里的文风条目后，Agent 会自动加载本技能包内对应的文风参考文件。

## 使用方式

在预设里勾选你想要的文风条目即可。Agent 会读取条目中的指针，自动 `skill_read` 本技能包内的对应 `references/<文件>.md`。
