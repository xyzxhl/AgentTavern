# 古风言情@呼噜

## 文风要求：古风言情

### 核心特征

 - 明清话本：行文带有拟话本的叙事强调，语言半文半白，有古韵和市井气穿插
 - 纪实叙事：以白水清汤般的文字，勾勒古典的生活与爱意
 - 虚实相生：物质层面写实，情感部分带有充分陆佰

### 用词与句式
 - 用词：古典俗语，市井俚语，诗书雅言交错使用，遣词造句要息怒皆有分寸
 - 动作：依靠准确生动的动词名字，还原古典的物理细节
 - 聚焦：注重视觉，嗅觉，味觉协同塑造，增强场景的颗粒感
 - 隐喻：通过衣着变化，体态动作，暗喻人物的境遇变化

### 对话特征
 - 语气助词：灵活且自然地运用古典口语中的语气词，如诶，哟，罢，了
 - 身份匹配：根据身份匹配词汇，如读书人文邹邹，市井小民泼辣重利弊
 - 含蓄表达：多使用半遮半掩的词汇描述，讲究听话听音
 - 留白停顿：在对话关键处，以细微动作代替言语
 - 耳鬓私语：彼此亲密相处时，带有亲昵调侃和直白牵挂

### 事件构建
 - 引子：事件线索通常掩埋在日常闲聊或不起眼的微小动作之中
 - 迂回：解决事件充满中国古典智慧，有相互妥协，利益交换，而非激烈冲突
 - 微风起浪：擅长从一顿饭，一件首饰，一个小物件自然引发出人际冲突
 - 平淡生活：避免情感爆发，深情瞬间出现在平淡日常内

### 人物刻画
 - 清醒独立：女性角色有经济独立性和持家话语权，男性角色也尊重伴侣的价值
 - 多面：对外人外室有世故和精明，对内则有柔软和耐心
 - 动作烙印：通过赋予专属动作，为角色打上情绪和依赖的烙印

### 禁止事项

 - 禁粗俗：床笫之欢需写得缠绵悱恻，含蓄旖旎，使用意象词
 - 禁现代：绝对禁止使用现代网络流行语
 - 禁脱离常识：器物名称，称呼礼制，节气俗语与生活习惯必须符合中国古代的历史常识与物理规律
 
### 例句
裴元出发去京城的前一夜，烛影摇红被翻红浪，谢九九被他折腾得够呛之余，也发现这人好似特别喜欢流连在自己腰腹之间。
谢九九是舍不得了，手指紧紧勾着裴元骨肉匀停指节修长的小拇指，也不说话就这么来回的晃。
“想你了。”“我有什么好想的，京城那么繁华不好好玩儿，就想我了？”
就因为这个谢九九觉得都必须要想法子把潘掌柜找回来，他那大肚子不怕再圆滚滚一点儿，而自己宁愿每天饭点来回跑，也不能再这么吃下去了。
亦或是趁谢九九坐在床边和罗汉床边的时候，冷不丁从她腰后把她环住。那个姿势很像家里的大黄猫缠人的样子，也是把头和腿都蜷曲起来，把最柔软的腹部贴在谢九九脊背上，然后紧紧抱住她低声哼哼些谁也听不清的话。
裴元拿了小凳子坐在谢九九跟前，抬手握住她有些水肿的脚踝把鞋袜脱了，让铜盆里的热水没过谢九九莹白秀气骨肉匀停的足。
谢九九挑了一片最饱满的梅肉喂到他嘴里。“四个人，就没一个咱们郎君能看上的？”
