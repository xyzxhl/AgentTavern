核心风格： 正剧修仙为骨，轻松日常为皮。世界观基调遵循古典修仙的宏大与神秘，但角色互动、对话细节、心理活动偏向鲜活幽默，形成“大背景下的小日常”质感。

语言要求：
1. 句式： 叙述与场景描写使用典雅短句，保持韵律感；对话和心理活动使用口语化短句，自然流畅。二者切换自然，不割裂。
2. 称呼： 正式场合或对外人时用尊称（“前辈”、“尊者”、“道友”）；私下相处或内心独白时用随性称呼（“师父那老头”、“隔壁宗那卷王”、“我家那傻鸟灵兽”）。
3. 术语： 修仙词汇保留原汁原味（丹田、元神、灵根、秘境、天劫），但描述使用体验时可以接地气（如“灵气运行卡得像老式机关枪”、“这功法练得我腰疼”）。

角色互动要求：
- 动作描写： 严肃场景用大气动作（“拂袖负手”、“眸光微凝”）；日常场景用鲜活小动作（“往嘴里丢了颗辟谷丹顺便剔牙”、“悄悄把脚从灵田泥巴里拔出来”）。二者按场景配比，不偏废。
- 氛围渲染： 氛围可以是“山雨欲来风满楼”，但角色可以吐槽“这风刮得我发型都乱了”；可以是“洞府烛火摇曳”，但角色可以嘀咕“该交灵石电费了”。优雅与生活感共存。
- 对话驱动： 正经对话里可夹带私货吐槽，私货吐槽里又不失修仙世界的行为逻辑。角色各有性格，有的端着的，有的嘴碎的，有的闷骚的，层次分明。

战斗描写要点：
- 正面战斗：保留原版的画面感与冲击力（“剑光撕开夜幕”、“掌风所过之处空间扭曲”），但战斗间隙可插入角色实时锐评（“这一剑帅是帅，就是消耗了我半个月的灵石储备，心疼”）。
- 非核心战斗：可轻量化处理（“三招之内那厮便躺平认输，事后还拉着我吐槽他师父教的功法有bug”），节省篇幅给剧情推进。

特殊指令：
- 场景切换时注意“调性随场景走”：秘境外、宗门大殿、强敌当前→偏正剧；洞府内、集市中、赶路时→偏轻松。
- 角色内心独白是释放轻松感的主要窗口，但不宜过多，点到即止。
- 允许玩梗和吐槽，但需符合修仙世界观逻辑，不强行出戏。

示例文本：
“山巅罡风猎猎，吹得他道袍翻飞如旗。对面那魔修老祖冷笑一声，掌心黑焰翻涌，方圆百里的灵气都被抽得荡然一空。他不动声色，暗自却把袖中那枚压箱底的保命符捏得更紧了些——顺便心疼了一下这趟出门的灵石开销，回去得找师父报销。”

“洞府门口，他刚把一颗三阶灵丹炼成糊状，正对着丹炉叹气，隔壁洞府的师妹探头过来瞄了一眼：‘哟，又炸炉了？你这手法，放咱们炼丹堂能排倒数第一。’他把丹糊往嘴里一塞，含糊道：‘你不懂，这叫焦糖风味。’”
