# 外部资料

> 给故事挂一份别人写的资料（一本小说、一段史料、一份专业手册），让它写的时候查。
>
> 解决的是**模型自己知识不够**的那一类：同人的设定与黑话、某个朝代的官职与器物、
> 一个专业领域的术语与流程。

## R40 · 给故事挂资料，它写的时候会去查

用户导入一份资料，这局故事写的时候就能查它。

**不包括**：把整份资料塞进上下文。资料动辄几十万字，塞不进，也不该塞——
每轮都带着一整本书，等于让模型在正确的一句和其余九万九千句之间自己挑。

## R41 · 一份资料能给很多局故事用

同一套同人设定、同一段史料，开多少局故事都用同一份。**改一次所有故事都跟着**。

**为什么**：同人写作最典型的场景就是同一套设定反复开新故事。
资料做成一局故事私有的，等于每开一局复制一遍。

## R42 · 它查了什么、查到什么，用户看得见

每一次检索都要看得见：**用了什么 query、命中了哪几段、来自资料的哪个位置**。

**为什么**：这条链路查不查得准，用户是唯一判得出来的人——他知道自己那份资料里有
什么。看不见的话，写错了他只会觉得"这模型不懂"，而不知道是没查到还是查错了。

## R43 · 查不到的时候，它自己判得出来

**这条链路不承诺查全。** 能不能找到取决于模型这一次的 query 问得对不对、
以及检索本身准不准——**两样都保证不了**。

所以系统要**自己判定这次检索成没成**：相关度不够时就报「没找到」，
而不是把几段勉强沾边的东西端上来。

**不包括**：给模型附一段「这可能不全，仅供参考」的话。**那是免责声明，不是机制**
——模型会忽略它，而它每次都占上下文。真正管用的是**系统替它做完那个判断**，
把结论给它：找到了，或者没找到。

**为什么勉强沾边的比没有更糟**：模型拿到几段不相关的资料，会当成相关的用——
写进剧情里的就是一段有出处、但出处对不上的东西。**而没找到，它至少知道自己不知道。**

## R44 · 整条链路可以关掉，关掉不留痕迹

关掉时工具根本不注册，提示词里也不提它。

**为什么**：绝大多数故事用不上这个。一个注册了但没资料可查的工具，
白占提示词体量、还会被试着调一次。

## R45 · 导入一份大资料要看得见进度

一本三十万字的小说建索引要花时间。导入之后要能看到**它进行到哪儿、什么时候能用**。

**不包括**：导入完成之前假装它已经能用。查一份还没建好索引的资料，
要明确说"还在建"，不是返回空。

## R46 · 把文件放进那个文件夹，就算交给它了

有一个固定的文件夹（`data/corpus_files/`）。**把 txt 丢进去就是导入**，
不用点上传、不用填表。

文件名就是这份资料的名字。**编码不用管**——GBK 的旧 txt 一样能读，
而界面上会写清它是按哪种编码读的。

**不包括**：让用户自己指定这个文件夹在哪。多一个可配的路径，就多一类
"我明明放了它怎么没看见"的问题，而这个功能本来就该是"丢进去就行"。

## R47 · 文件夹里加了、改了、删了，界面上标出来；更新与否你说了算

系统**不自动同步**。它只告诉你文件夹和知识库现在对不上的地方：

| | |
|---|---|
| **新文件** | 还没处理过 |
| **已修改** | 处理过，但文件后来改了 |
| **源文件已删除** | 知识库里还有，文件夹里没了 |

要不要照着更新，**你按了才算**。

**为什么不自动**：处理一份大资料要花时间也要花钱，而且你可能只是在文件夹里
临时改点什么。**自动同步等于让编辑器的每一次保存都触发一次重建。**

**为什么改了不立刻用新的**：知识库里那份是**处理那一刻的快照**，检索报的位置
指的就是它。跟着活文件走的话，你改一个字，之前所有引文指的位置就全错了位，
**而没有任何地方会报错**。

**源文件删了、你也确认更新之后，这份资料就真的没了**——下一次检索不该再查到它。
有故事挂着它的话，界面会先告诉你是哪几局，但**不拦着你**。

## R48 · Word 和 PDF 也能直接放进去

纯文本（txt / md / json / yaml / csv）直接读；**Word 和 PDF 先解析成文字再处理**。

**扫描件读不出字，要当场说清**。一份扫描的 PDF 里没有文字层，抽出来是空的——
不说的话，你会得到一份"建好了但怎么查都查不到"的资料，而那看起来和
"这资料里确实没有"一模一样。

**不包括**：OCR。图片里的字不认。

**检索报的位置指的是解析之后的那份文字**，不是 PDF 的页码——
界面上能直接看那份文字，对着它数得到。

---

## 这一层和别的检索不一样，用户要知道

系统里其它几样东西——世界设定、状态、剧情历史——都保证**模型知道有什么存在**，
只是精度有高有低。**外部资料做不到这一点**：它太大，装不下一份完整的目录，
而且用户给的资料未必有结构可言。

所以它的定位是**增强，不是依据**：

| | 保证 |
|---|---|
| 设定 / 状态 / 历史 | 模型知道有什么，查不查得到不影响它知不知道存在 |
| **外部资料** | **只保证查过了，不保证查全** |

这条差别写在这里，是因为它会改变用户怎么用它：
**指望它兜底会失望，拿它增强会有收获。**
