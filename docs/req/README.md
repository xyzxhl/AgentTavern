## 这是什么产品

基于 agent 的 AI 角色扮演（airp）系统。**全新实现，不 fork SillyTavern / TauriTavern**——
不承担兼容性包袱。

两个创新点：

- **用 agent 技术提高生成质量**：主动检索、显式状态维护，而不是把一切拼进一个提示词。
- **探索 airp agent 化之后的新用户体验**。

**每一轮都走 agent，不保留"直接生成"的快路径。** 这是一条产品立场，不是性能取舍：
留一条快路径，等于承认 agent 那条路平时不值得走。

## 一个术语

一轮生成叫一个 **run**，它在故事树上留下一个**节点**。用户看到的「这一轮」
和系统里的 run、节点是同一个东西。其余术语见 [Glossary.md](../Glossary.md)。
