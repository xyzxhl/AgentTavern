## Step 7 归零核对：**不能用词边界**

计划里写的是 `git grep -nE '\bD[0-9]{1,3}\b'`。**那个正则会漏。**

台账里有 `D122①` `D145②` `D152①` 这种带子条目序号的引用，而 `①` 在 Unicode 下算
alnum，于是 `D122` 和 `①` 之间**没有词边界**，`\bD122\b` 匹配不上。写这份映射表时
自查就被它骗过一次——报"漏了 3 条"，实际一条没漏。

归零核对一律用**不带尾部边界**的形式：

```bash
git grep -nE 'D[0-9]{1,3}' -- . ':!docs/sillytavern_preset_example'
```
