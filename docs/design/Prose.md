# 文风：怎么量，以及量出来的东西怎么用

> 参考文本在 [`../novel_example/`](../novel_example/)，探针是 `agenttavern.bench.style_probe`。
> 决策见 D122 / D124 / D126。

## 1. 为什么会有这一层

文风是归因六类里**唯一没有参照物的一类**（D83）——「写得好不好」没有对照物，AI
判不了，只能人看。所以 C4 阶段长期卡着：改一版提示词，读几段正文，凭感觉说
「好像好点了」，下一轮又推翻。

参考文本改变的不是「好不好」，而是**「像不像」**：

> **有了参照物，一部分文风问题就从品味判断变成了可比的差值。**

注意范围：它**不能**回答「这段写得好吗」，只能回答「这段和一批人类网文在某个可数
的维度上差多远」。后者不是前者，但它足以**指路**——告诉我该去读哪一段。

## 2. 铁律：只产数，不判分

> **这些数不进 `checks.py`，不进 grader，不参与任何通过/不通过的判定。**

理由是 D85 那条最隐蔽的伤害：**模型会为了满足检查器而牺牲质量，而检查器永远不会
告警**。「语气词密度不低于 2‰」这样的约束，换来的会是硬塞的「啊」「吧」——指标绿了，
文字更差了，而且没有任何信号提示这件事发生了。

同一条也解释了为什么探针留在 `bench/` 而不是 `orchestration/checks.py`：
后者是运行时路径，前者是给人读的报告。

## 3. 判别式：只看六本一致、而我们明显在外的

六本参考横跨六个题材（都市重生商战 / 游戏惊悚 / 冷硬现实 / 无限流灵异 /
无限流战斗 / 仙侠幽默）。**同一个指标在它们之间的差异，常常比「我们 vs 参考」的
差异还大**——比如段均字从 28.1 到 63.4，对白段占比从 26.7% 到 53.0%。

所以拿单本当标准会得出假结论。实测踩过一次：只有参考1 时我判定「我们的『他』是
参考的 3.3 倍」，六本比完之后人称代词的范围是 16.8–30.2‰，我们的 29.3 落在里面，
**那条结论被自己的数据推翻了**。

判别式因此是：

| 情形 | 结论 |
|---|---|
| 六本内部就分散 | 这是题材差异，**不看** |
| 六本一致、我们在里面 | 没问题，**不动** |
| **六本一致、我们完全在外** | 值得去读那段文本，找原因 |

没有语气——这恰恰是很典型的一类痕迹。

## 5. 量出来之后做了什么

三次改动都是**先定位到具体某行提示词，再删/改那一行**，不是加一条新规则：

| 指标异常 | 定位到 | 处置 | 结果 |
|---|---|---|---|
| ~~破折号 13×~~ | ~~提示词自己破折号 7.03‰~~ | 把提示词里的 `——` 换成句号逗号 | ❌ **结论作废**，见下 |
| 收尾定式 9/10 轮抛问题 | `_speaking_rule` 两串例子**都把「问题」排第一** | 删掉那两串例子 | **9/10 → 0/5** |
| 正文跟着细纲的腔调走？ | 不成立：细纲破折号降 36%，正文纹丝不动 | 只在 writer 侧明写「细纲不是范本」（D129） | 待测 |

**第一行是个反面教材，保留是为了不再走回头路。** 当时的推理链看着很完整：提示词
破折号 7.03‰、产出 7.32‰，几乎一比一；清洗后降到 4.40。**三个数都对，结论是错的**
——§6 量出同配置下的抖动范围是 2.08–9.03，那几个数全在带子里。

站得住的只剩两条：

- **D124 列举里排第一的那个会变成默认选项。** 它站得住是因为效应量足够大
  （9/10 → 0/5），远超任何抖动。删了之后**不要另找一串例子替换**，换一串只会换一个定式。
- **D122 的负结果部分**：叹号与省略号在提示词里是 0、产出里也一直是 0。
  **零方差的零才是信号**，而 D122 的正面部分（镜像效应）已作废。

## 6. 第一步永远是量方差，不是改东西

> **同一份细纲、同一份提示词、连跑 5 次，这些指标自己就在大幅跳动。**

`writer_lab --repeat 5 --limit 2` 的实测（两份细纲各 5 次重写，什么都没改）：

| 指标 | 均值 | 最小 | 最大 | 极差/均值 |
|---|---|---|---|---|
| 破折号 ‰ | 5.72 / 5.16 | 4.48 / **2.08** | **9.03** / 7.62 | **79% / 107%** |
| 语气词 ‰ | 2.34 / 1.26 | 1.60 / 0.00 | 3.63 / 2.33 | 87% / 184% |
| 程度副词 ‰ | 1.98 / 0.42 | 1.60 / 0.00 | 2.42 / 2.08 | 41% / 500% |
| 疑问句 % | 6.41 / 8.58 | 4.76 / 5.26 | 9.09 / 11.11 | 68% |
| **连接词 ‰** | **0.00** | **0** | **0** | **0%** |
| **省略号 ‰** | **0.00** | **0** | **0** | **0%** |

破折号在**什么都不改**的情况下自己跑遍 2.08–9.03。而此前跨轮报过的四个数
（7.32 / 4.40 / 5.42 / 5.38）**全部落在这条带子里**——那三轮里我一直在解释随机数。

由此得到本文最重要的一条判据：

> **会跳动的低值，和从不出现的零，是两件事。**
> 前者是这次少了；后者是模型根本不产出这个东西，那才是系统性的。

十次重写里**只有连接词与省略号是恒定的零**（方差为 0），而六本参考分别是
2.2–6.0‰ 和 2.1–10.3‰。**七条"偏离"经方差检验后只剩这两条。**

这也解释了一个一直没想通的现象：为什么"清洗提示词标点"每次看着都有点效果、
却从来推不到位——**因为没有效果**。

### 因此流程是三步，顺序不能换

1. **量方差**：当前配置下 `--repeat 5`，得到每个指标的抖动范围。
2. **只看零方差的偏离**，或效应明显大于方差的那些。
3. **一次只动一处**，改完再跑同样的 `--repeat`，比分布而不是比单值。

第 1 步排在第 3 步前面，因为**动一处之后你仍然读不出效果，如果不知道噪声有多大**。

## 7. 测量方法上的两个坑（都踩过）

**细纲必须固定**（D126）。此前每次"调 writer"都是重跑整条 `bench --scenario pulp`，
**那会把细纲一起重新生成**——比较的是「不同提示词 + 不同细纲」的产出，writer 的
变化和 director 的变化混在一起。连着三轮都是这么比的。现在用
`agenttavern.bench.writer_lab` 从落盘节点取固定细纲。

**一次只动一处。** 有一次我在替换标点时"顺手"把 `_CRAFT` 的一句话改得更准确了，
于是段长句长那一片的变化归不了因。**改提示词时「顺手把话说得更好」就是在偷偷加变量。**

## 8. 向 SillyTavern preset 学写法

`../sillytavern_preset_example/` 是**经过实战验证**的提示词。它值钱的地方有两处：
一是那批「杀八股」正则（见 §9），二是**提示词本身的写法**。

### 差别只有一条：它给具体动作，我给元层判据

| 同一个意思 | preset 的写法 | 我原来的写法 |
|---|---|---|
| 别贴情绪标签 | 把愤怒写成一句没说完的话、放重的杯子、突然改口、绕开的视线 | **判断标准是**它有没有承载住情感重量 |
| 别用熟句开头 | 不要写「像一颗石子投入心湖」「空气中泛起涟漪」「沉默蔓延开来」 | 不要每段都从环境起笔 |
| 比喻要贴身 | 一个厨子会想到锅气，一个学生会想到试卷，一个士兵会想到靴底的泥 | （我完全没写） |
| 该删就删 | **每段写完问一句：删掉这句话，剧情、人物或气氛有没有少东西？没有就删** | 缺什么补什么，补的是实质，不是长度 |

最后一行是被点名的那条。同一个意思，**它给出了可执行的自检问句，我给了一句格言**。

形式上还有两点：preset 几乎不用粗体，段落是流畅散文；我满屏 `**`，读起来像条例汇编。
它常用「X，就写 Y」的条件句，直接给操作，而不是先立判据再让模型自己推。

### 这与 D124 不矛盾，但要补一句

D124 说「列举里排第一的会变成默认选项，删了别另找一串例子替换」，而 preset 大量用例子。
区别在**例子在解释什么**：

- 我删掉的那两串枚举的是**产出形态清单**（细纲该停在什么上），模型照着挑第一个，
  实测 9/10 轮抛问题。
- preset 的「厨子/学生/士兵」演示的是**一个词的意思**（什么叫「贴身」），
  三个并列不是让它选一个。

**同一串例子，放在「何时停」是判据，放在「写什么」就是模板。** 我当初把这两件事
写成了一句，枚举于是从判据退化成了内容模板。preset 的「禁止抢话」里保留了同样的
枚举（「向玩家提出了问题或给出了明确选项 / 做出了需要玩家回应才能继续的动作 /
已制造出一个只能由玩家来推动的新局面」），但它挂在**停止条件**下，不是收尾内容。

### 从 preset 纳入 director 的

| 采纳 | 内容 | 为什么 |
|---|---|---|
| ✅ | **转述先判类型**：角色扮演输入 / 指令元输入，两条分支各写各的处理 | 原先散在五个 bullet 里，边界靠读者自己拼 |
| ✅ | **不要形成固定节奏**：不是每个动作后面都得跟一个别人的反应 | 我们完全没有，而它正对 `gufeng` 读出的句式重复 |
| ⬜ | **抢话分四档且量化**（「至少三句话」「至少两个行动」） | 我们是 `bool` 二值且不量化。要动 `ControlDimensions`，另排 |
| ⬜ | **大纲阶段字段**（主线进度 / 当前阶段 / 下一阶段） | director 目前**没有任何长弧意识**，这是真缺口。goal_manager 的中间状态只在有 goal 时存在，不覆盖无 goal 的日常长弧 |
| ❌ | **伏笔状态**（伏笔名 + 已埋设/已回收） | 我们已有且更清爽：D109 悬置类 + 兑现即删，state 里的悬置项**始终等于当前还欠着的账** |

## 9. 八股探针：社区正则

`agenttavern.bench.antipatterns` 的模式全部来自 preset 的「杀八股」正则。
**它们比自造指标可信，不是因为更精确，而是因为被需求验证过**——有人真的被这些
句式烦到要写正则去删。

同样值得注意的是**他们选择的解法：事后正则删除，而不是在提示词里禁止**。
这与实测一致（D130：对模型原生语体的引导推不动）。

十条里我们干净避开八条（不是X而是Y、一丝一抹、微不可察、指节泛白、
由于/极其/生理性的、语气像…、一个动作/一个笑容），只有两条超标：

| | 参考 1–6 | 我们（三批一致） |
|---|---|---|
| 突然 / 忽然 | 0.14–0.85 | 0.96–1.11 |
| **破折号** | 0.00–0.35 | **3.77–5.03** |

破折号是**唯一一条什么都推不动的**：清 writer 提示词、清 director 提示词、
换整套写法，七次测量全在 3.5–5.5。社区对它的处理也是 `/——/g` 直接替换。

## 10. 已知不足

- 「主从句比例」用**连接词密度**做代理。中文没有形态标记，真要分主从得上句法分析。
- 参考文本都是网文，没有覆盖 `noir` / `data` 那种克制文学向的文风。**拿网文腔去量
  它们是量错尺子**，所以表里 noir 那一列只用来看七条共性，不用来看题材相关的项。
- 六本仍然是小样本。「六本一致」只是比「一本」强，不是统计意义上的一致。
