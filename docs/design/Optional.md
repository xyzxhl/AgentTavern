# Optional 机制：真实性与戏剧性的取舍

> 与长程一致性（[State.md](State.md)，必做）相对，本文档记录三项 optional 机制的定位、共同代价与共同设计原则。**均不进默认路径。**

## 1. 三项机制

| 机制 | 解决什么 | 已知状态 | 主要代价 |
|---|---|---|---|
| **多 agent 角色化**（每个 agent 代表一个角色） | 角色行为逻辑、知情不符（信息不对称） | 有效 | 成本超线性（见 §3）；真实性削弱戏剧性 |
| **规则化**（数值、检定、系统） | 逻辑推演的确定性 | 已有被验证的方案 | 真实性削弱戏剧性；**可扩展性**——会话中新系统要不要规则化 |
| **自主演化**（世界在用户不主导时推进） | 世界感、临场感 | —— | 后台维护与信息生产成本；真实性削弱戏剧性 |

三者均只适合部分场景，不进入默认路径。

**自主演化应归入创新点 (b)**：它不降低错误率，它改变世界的呈现方式。按错误率评估它必然不划算——"后台维护和生产信息的成本不敌"正是这么算出来的。它的评估标准应是"用户体验是否真的改变"，与"长循环自主创作"属同一族（世界在用户不主导时继续推进），成本账按 UX 收益算。

规则化的可扩展性问题已有处理方向，见 [State.md](State.md) §2：新系统就是几个自由键，不规则化。

## 2. 核心设计原则：强度旋钮，而非开关

**"真实性削弱戏剧性"不是绝对的。对逻辑能力不足的模型，这几种手段能降低其逻辑推理的负担。**

这句话改变了这三项机制的定位：它们不是质量功能，是**模型能力的补偿机制**。它们解决的是模型推理能力不足，因此收益随模型能力提升而递减——这正是它们与长程一致性（解决上下文窗口的物理限制，收益不随模型能力消失）的分界线。

推论：**不做成"要不要有"的布尔开关，做成强度旋钮，且旋钮与模型能力挂钩。**

- 弱模型 → 调高：卸载推理负担，用机制换正确性
- 强模型 → 调低：放手让它即兴，保住戏剧性

这样"真实性 vs 戏剧性"从一个需要站队的取舍，变成一个可配置、可实验的量。同时它也天然接入 [../Principles.md](../Principles.md) P19 的消融方案——旋钮档位本身就是消融维度。

## 3. 为什么多 agent 的成本是超线性的

"真实性削弱戏剧性"的机制值得写清楚，因为它决定了成本估算：

**戏剧性需要一个全知的、为观众服务的叙事意志**，而真实性模拟恰恰是取消这个意志。独立的角色 agent 各自追求自己的目标，没有任何一方负责"让这一幕好看"——真实的人不会在恰当的时刻说恰当的话，真实的信息传播也不会及时制造出戏剧需要的误会。

因此角色 agent 化**不是把正文生成拆成 N 份，而是拆成 N 份再补上一项新工作**：恢复被取消的叙事意志。成本是超线性的，且这项新工作与 director 的推演职责重叠，需要一并重新划分。

这是"只适合部分场景"的结构性原因，不仅仅是 token 更贵。

同一机制也解释了规则化的代价：检定在关键时刻掷出失败会产生反高潮，本质上同样是让确定性规则覆盖了叙事意志。

## 4. 开放问题

- 旋钮的档位如何定义？是每项机制独立一个旋钮，还是有一个统一的"模拟强度"总控？
- 旋钮由谁调？用户显式设置 / 按所选模型自动推荐 / 运行时按错误率自适应。
- 若引入角色 agent 化，"恢复叙事意志"这项新工作与 director 的推演职责如何切分。
