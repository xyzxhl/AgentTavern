# 术语

> 术语混用是设计漂移最常见的入口。这里的每一条都对应一次实际的澄清，不是词典条目。

## 时间轴上的单位

对用户提交而言，**一条从队列出队的顶层 user input = 一个 turn**。goal_manager 生成的
模拟输入沿用同一条路径，也会开启一个 turn。

turn 是输入与响应的**逻辑位置**；重生成不会开启下一个 turn，而是在同一位置创建兄弟版本。
每个完成版本各自满足 **run = node version = 一份细纲 = 一份正文**（S1）。

**插话不是新的 turn input。** 它发生在当前 turn 内：纠正会先打断正在执行的操作再追加，
引导会等当前操作结束、在下一个合法操作边界追加。只有排队输入才会在当前 turn 完成后
开启下一个 turn。

上一 turn 的直接编辑窗口从它完成时开始，到下一条顶层 user input 成功提交时结束。
有 run 正在执行或挂起时不能编辑；挂起草稿不会为了编辑被系统自动丢弃。

| 词 | 含义 |
|---|---|
| **run** | 一个 turn 版本的一次完整生成：从取得顶层输入到提交正文 |
| **node** | turn 的一个完成版本；内容包括正文、state 增量与偏离报告；细纲只是 run 内临时制品 |
| **turn** | 一条顶层输入驱动的逻辑交互位置；插话与重生成都不增加 turn 数 |

**不使用 "beat"。** 它曾同时指"一轮生成"和"剧情节拍"，是歧义来源。

注意与 TauriTavern 的 `run` 区分：那里一个 run 是 request-scoped 的一次生成，与分支无关；这里 run 就是节点。

## 三种数据，按「谁改变它」区分（S52）

| 词 | 内容 | 由谁改变 |
|---|---|---|
| **state** | 结构化的世界当前状态 | **剧情推进**（state_manager 每 run 末提交增量）或用户纠正上一 turn |
| **worldinfo** | 静态设定：角色卡、世界观、背景 | **用户**（元操作「改设定」） |
| **history** | 当前路径上过往 run 的顶层输入、插话与正文；正文是唯一叙事权威 | 每 run 追加；上一 turn 的编辑窗口内可直接修改会进入后续 context 的内容 |

thinking 与 tool call/result 只活在当前 turn；挂起时进草稿供恢复，完成后不进入 history。

**state 与 history 不是并列的两份记录。** 信息本体在 history；**state 是它的一条捷径**（S36）——把每轮都要用、又不该每次回头翻的那几条拎到眼前。因此 state 里删掉一个键不等于丢了那件事，它仍在 history 里。

**`ledger`、`账本`、`后台数据` 三词已废弃。** 前者来自另一个项目且暗示会计语义；后两者含混——worldinfo 也在"后台"。

灰区：同一实体可以两边都有——「他们是兄妹」属 worldinfo，「他们现在决裂了」属 state。

## worldbook：一级资产（S68 / S67 / S65 / S63）

worldbook 是**用户编写和维护的结构化设定资产**。它**不属于任何 session**——一份能开出
好几局故事，改一次所有故事都跟着（S63）。上表里的 worldinfo 和 state 都是它的投影。

**它只有条目，没有字段**（S64，除了自己的名字）。题材与基调、剧情尺度也是条目——
它们和「旧货店在老城区一条窄巷尽头」是同一种东西：一段关于这个世界的字。

条目分四类（S168/S67/S65）：

| 类型 | 装什么 | 落到哪 | 之后由谁改 |
|---|---|---|---|
| `world` | 一段不受限制的文本：地方、组织、规矩、历史、**题材与基调、剧情尺度** | worldinfo | 用户 |
| `character` | 正文 + **语言习惯**（`voice`）+ 是否用户扮演（`is_player`） | worldinfo（`voice` 只进 writer） | 用户 |
| `state` | 一棵键值树：**初始状态** | 故事第一帧的 state | 剧情推进 |
| `opening` | 新故事可选的一段开场正文 | session 的固定历史起点 | 创建后不再变化 |

`is_player` 是 worldbook 级设定，不是 session 覆盖项。因此复用同一份 worldbook 的
所有 session 共用同一个「用户扮演谁」；想换玩家角色，需要换或修改 worldbook。

**为什么初始状态要单独一类：** 一条设定常常是混的——角色的性格、背景不会变，
而他现在在哪、知道什么会变。不分开的话模型只能把后者从设定正文里**抄**进 state，
而副本会在设定被改动后与之分叉。分开之后这个动机就没了。附带好处是那些键成为
**命名锚点**：模型看见已有的 `时间`、`林昭.知情`，就会去改它们，而不是自己发明一套。

（「种子 / seeds」这个叫法已废弃，S67：它暗示"发芽之后就与它无关"，
而实际语义恰恰相反——它就是这局故事第一帧的状态。）

### 改设定，什么时候生效

**这条同时回答了「一份设定被好几局故事共用」的全部问题**（S63）：

| | 什么时候读 | 所以改它 |
|---|---|---|
| 初始状态 | **只在第 0 轮之前**——第一轮开始时冻结进 `session.json`（S37） | 只对还没开始的故事有效 |
| 开场白候选 | 创建 session 时选择并复制（S168） | 只影响之后新建的故事 |
| 世界与角色 | **每轮现读** | 直接影响所有故事的下一轮 |

后者是对的：静态设定是「这个世界是什么」，改它等于改角色卡。前者也是对的：
第五轮写着「她掏出钥匙」而钥匙来自初始状态，把它删掉那一轮就凭空多了一把
不存在的钥匙，且没有任何地方会报错。

## 四个 agent

| 词 | 职责 | 关键约束 |
|---|---|---|
| **director** | 主 agent，tool loop。读正文历史并推演，产出**无文风约束的文章**（细纲） | 不读文风；避免重复已完成剧情 |
| **writer** | 纯渲染，单次调用。把细纲按文风改写成正文 | 不增删实质内容 |
| **state_manager** | tool loop，run 末。只以正文为叙事输入，写状态增量 | **state 的唯一写者**（S7） |
| **goal_manager** | tool loop，跨 run 累积产品记录。替用户写输入、核对进度、判目标去向 | 只在有 goal 时存在；终态只有 `done` / `failed`（S92）；**在 run 末跑，开场那次例外**（S100） |

**前两个是必然存在的，后两个各自可关**：`state` 关掉则 state_manager 不跑，没有 goal 则 goal_manager 不出场。

**细纲不是大纲。** 它是一篇完整文章，写清事件、对白、实体细节——只是不受文风约束。
writer 不会补充任何东西，凡细纲里没有的就不会出现在成品里。它只在当前 turn 内作为
director 到 writer 的交接制品，不写入完成节点，也不进入后续模型 context。

**「goal 判定」这个叫法已废弃。** 它曾是 run 末一次输出 yes/no 的窄调用；现在是
`goal_manager`，跨 run 的产品记录 + 四个工具（S92）。叫「管理者」而不是「判定者」，
因为判定只是它几件事里的一件。历史记录不含已经结束 turn 的 thinking 或工具往返。

## 三类现行配置（S81 / P14）

**这三类是判据，不是分区**（S80）：它们回答「这东西改变什么」，据此判断一个新旋钮
该不该存在；除了目标，全部住进 agent 管理，并且是**服务级**取值。

| 词 | 改变什么 | 住在哪 |
|---|---|---|
| **元指令** | **目标**——这局故事要达成什么 | session（只剩 `goal`） |
| **控制维度** | **处理方式**——每轮怎么处理 | agent 管理：某个 `choice` 的 `selected` |
| **能力开关** | **系统能做什么**——哪些工具存在 | agent 管理：某个工具 / 提示词 / context 上的开关 |

`goal` 属**元指令**，不是模式——有无 goal 系统跑法一样，只是 run 末多一个判定
（外加目标刚设上时先规划一次，S100）。

**「展开密度」这个共享维度已取消**（S80）：它曾是一个取值喂三处（director 的事件密度、
writer 的铺陈程度、goal_manager 的推进节奏），现在是三个各自独立、服务级的 `choice`。
**没有「单轮覆盖」**（S80）：取值只剩一处，没有被覆盖的对象了。

## 其他

| 词 | 含义 |
|---|---|
| **state 增量（delta）** | 一个 run 的状态变化。**权威数据**——当前状态是沿路径重放增量的结果 |
| **默认包** | 无条件注入 director 上下文的那部分 state（外层路径 + 未折叠叶值） |
| **偏离报告** | writer 若增删了实质内容时的报告，通常为空 |
| **trace** | 完整可回看的审计记录，不是模型 context 的重放来源。**开发者模式**，默认关闭 |
| **采样标记** | eval 用的可疑样本提示。**从不影响运行时行为** |
